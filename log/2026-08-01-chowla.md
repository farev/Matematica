# 2026-08-01 — chowla

**Target.** Two threads off the 2026-07-29 session: extend the certified
sign-pattern coverage of λ past k = 30, and build a sharper instrument out of
the coverage data than the single number N_k. The sandbox forced a third,
unplanned target first — it has gcc, four cores and no network, and **no
NumPy**, so every script in `conjectures/chowla/` was unrunnable on it. The
coverage pipeline had to be rebuilt from scratch in C, which turned the
obstacle into the more useful thing: an independent audit of last session's

**Result.**

*CERTIFIED — clean-room reproduction.* `lambda_coverage.c` (exact segmented
Liouville sieve, integer-only critical path, sharing no code with the NumPy
pipeline) reproduces **all thirty** previously certified coverage values

`fineA_coverage.csv`, `coverage_ext.csv` and `coverage_2830.csv` — plus
L(10^j) for j = 1..8. A third implementation, pure-Python trial division
(`verify_coverage.py`), independently confirms k = 1..14. The 2026-07-29
coverage census stands.

*NUMERICAL — the first-occurrence spectrum.* The coverage census throws away
2^k − 1 numbers and keeps the maximum. Recording the first occurrence of every
pattern instead gives a parameter-free per-pattern prediction, because for an
i.i.d. fair coin the expected waiting time for a word w is exactly Conway's
leading number A(w) = Σ_j δ_j(w)·2^j. Scoring R(w) = (start + k − 1)/A(w),
model E[R] = 1, at k = 24 over all 16,777,216 patterns, against 32 i.i.d.
fair-coin control streams pushed through the identical code path:

- λ mean R = 1.000123; controls 0.999953 ± 0.000319 → **+0.53 control-σ**
  (rank 23/33). Control ensemble mean is −0.8 SE from the exact model value 1,
  so the statistic is unbiased.
- popcount slope: λ −2.64·10⁻⁴, controls −1.10·10⁻⁴ ± 3.53·10⁻⁴ → −0.44σ; and
  the slope correlates r = +0.80 across controls with the stream's own realised
  one-point bias L(10⁷)/10⁷, so λ's value is what its known negative bias
  predicts (residual −0.56σ).
- overlap-class means flat at 1.000, confirming the Conway normalisation.

So the length-24 window statistics of λ are indistinguishable from a fair coin
at ~3·10⁻⁴ resolution — a 24-point statement in a range where the two-point
conjecture is open. Evidence, nothing more; the parity barrier predicts exactly
this abundance of unusable pseudorandomness.

**What failed.**

- *An ensemble of controls that was secretly one control.* The PRNG stream was
  seeded `sm64(n ⊕ seed)`. For small seeds `n ⊕ seed` only permutes n inside a
  short block, so every seed produced a stream with the **same bit multiset** —
  all reported L(10⁸) = +16362 to within 2. The ensemble dispersion collapsed
  and λ's popcount slope read as a **4.4σ anomaly**. It was not; with
  decorrelated seeding the identical λ measurement is −0.44σ. The instrument's
  own control caught this, which is the whole reason for having one. Both
  numbers are left in the record.
- *k = 28 spectrum, abandoned on cost.* Resolution improves like 2^{−k/2}, so
  k = 28 would sharpen the null fourfold, but it needs about nine runs to
  ~10^10 each and could not share the machine with the main computation.
- *Literature, entirely.* The proxy returns 403 for every host — arXiv, OEIS,
  everything. No citation is made this session that was not already checked
  against a primary source in an earlier one. The claim that N_k is new to OEIS
  is inherited from session 1 and was **not** re-checked.
- *A parser bug of my own*, caught by validation rather than by an error
  message: the `--ks` list parser silently dropped entries past the sixteenth,
  so k = 24 vanished from a run without complaint.
