# New exact values of generalized off-diagonal Schur numbers

*Session note, 2026-08-07. AI-assisted (Claude); disclosed per repository
policy. All computations exact; every boundary verdict carries an
independently checked certificate.*

## Abstract

We compute **eleven new exact values** of the generalized off-diagonal Schur
numbers `S(3;s,t,u)` — the first new values in this family since Ahmed–Schaal
(Exp. Math. 2016) — with machine-checkable certificates on both sides of
every boundary: a DRUP unsatisfiability proof at `S`, verified by an
independent reverse-unit-propagation checker, and an explicit valid coloring
at `S−1`, verified by an independent solution-enumeration algorithm. The four
values with `4 ≤ s ≤ t ≤ u` — `S(3;4,4,8) = 87`, `S(3;4,4,9) = 98`,
`S(3;4,5,8) = 111`, `S(3;4,6,7) = 118` — each decide a previously open
instance of Ahmed–Schaal Conjecture 2.1 (`S = stu−tu−u−1`), and all four
confirm it. The seven values with `s = 3` — `S(3;3,3,u) = 59, 68, 77, 86`
for `u = 8,…,11`, `S(3;3,4,8) = 67`, `S(3;3,4,9) = 78`, `S(3;3,5,8) = 91` —
extend a family for which no formula is known or conjectured, only Song–Mao's
strict lower bound (April 2026). Enumerating **all** extremal colorings shows
the `(3,3,u)` family is governed, at every computed size except `u = 7`, by a
single rigid skeleton with `u−2` free ternary slots (`2·3^{u−2}` extremal
colorings, maximal `L(u)`-class exactly `5(u−2)`), giving `S(3;3,3,u) = 9u−13`
at `u ∈ {3,4,5,6,8,9,10,11}` — stated as Conjecture A for all `u ≠ 7` after
it predicted the value, the extremal count, the slot positions and the class
maximum at `u = 10` and the value at `u = 11` in advance of computation. At
`u = 7` the value drops exactly one below the line and the skeleton
factorization fails; the deficit belongs to the two Schur classes, not the
`L(7)` class. The pipeline reproduces every published enumeration count of
Ahmed–Schaal's Theorems 2.1–2.10 and the unique `(3,4,5)` extremal coloring
character for character.

## 1. Definitions

For `t ≥ 3` let `L(t)` be the equation `x₁ + ⋯ + x_{t−1} = x_t` over positive
integers, repeats allowed. For `k ≥ 1` and parameters `t₀,…,t_{k−1} ≥ 3`,
`S(k;t₀,…,t_{k−1})` is the least `m` such that for every map
`f: {1,…,m} → {0,…,k−1}` some color `i` contains a monochromatic solution of
`L(t_i)`. A coloring with no such solution is *valid*; the existence of a
valid coloring of `[1,n]` proves `S > n`. Conventions follow the primary
source exactly (Ahmed–Schaal §1–2; e.g. `S(3;3,3,3) = 14`, and partial
repetition such as `5+5+13 = 23` counts as a solution of `L(4)`).

Known before this session (full table in `data/published_values.csv`):
the 26 Ahmed–Schaal values (with three diagonal values), the diagonal formula
`S(3;t,t,t) = t³−t²−t−1` (Boza–Marín–Revuelta–Sanz 2019, all `t`), the 2-color
family in closed form (Beutelspacher–Brestovansky 1982; Robertson–Schaal
2001), `S(5) = 161` (Heule 2017), and the general lower bound

    S(k;t₀,…,t_{k−1}) ≥ ∏ t_j − Σ_{i≥1} ∏_{j≥i} t_j − 1     (Thm 2.11, sandwich)

Ahmed–Schaal **Conjecture 2.1**: equality holds for `4 ≤ s ≤ t ≤ u` (`k = 3`).
**Conjecture 2.2** (now Song–Mao's theorem): strict inequality for `s = 3`.

## 2. Method

**Encoding.** Variables `v(x,j)` for `x ∈ [1,n]`, `j < k`; one at-least-one
clause per `x`; for color `j`, one clause `¬v(a₁,j) ∨ ⋯` per distinct support
set `{a₁,…} = {x₁,…,x_{t_j−1}, Σx_i}` of a solution of `L(t_j)` inside
`[1,n]`. Support sets are generated by enumerating nondecreasing summand
tuples (partitions), visiting each distinct clause once; the enumerator was
cross-validated against brute-force product enumeration on 15 `(t,n)` cells
(§4). No at-most-one clauses are needed for decision: constraints are
monotone decreasing in each color class, so any satisfying assignment projects
to a valid coloring. For extremal-coloring *enumeration*, pairwise
at-most-one clauses are added so models biject with colorings.

**Certificates.** Boundary UNSAT runs use Glucose 4.2 with DRUP proof
logging; every proof is checked by `tools/satcert/rup_check` (an independent
forward RUP checker written from the definition, validated 2026-08-05
including negative controls). Boundary SAT runs export the coloring, checked
by `verify_witness.py`: for each color class `S_j` it computes the iterated
sumset of exactly `t_j−1` summands from `S_j` via bitset convolution and
intersects with `S_j` — an algorithm sharing no code or method with the
encoder — and reconstructs an explicit violating tuple if one exists.
Exploration (locating unknown values before certification) uses Cadical 1.5.3
probes; **every** value claimed below is certified by the Glucose+DRUP /
verified-witness boundary pair regardless of how it was located.

**Hardware.** 4 cores, 15 GB RAM; solvers single-threaded; the pipeline is
deterministic end to end (no seeds exist). Per-run wall times and proof sizes
in `data/results_a1.csv` and `data/lane_*.log`.

  `(3,6,7) = 107` control run through the full certified-climb path.
  Every climb's first probe sits at Song–Mao's proved lower bound
  `2tu−u−1` and came back SAT, as their theorem requires, in all cases.
- **Enumeration controls**: the `--enum` mode reproduces every extremal-
  coloring count published in Ahmed–Schaal Theorems 2.1–2.10 exactly:
  18, 54, 162, 846, 8, **1**, 112, 96, 3584, 9488. Exact model-count
  agreement across ten instances is the strongest validation in this note:
  an encoding with a missing constraint overcounts, one with a spurious
  constraint undercounts.
- **Negative controls**: a corrupted witness (two elements forced into one
  color to create `2+2 = 4`) is rejected by `verify_witness.py`; injected
  non-RUP and truncated DRUP proofs are rejected by `rup_check` (satcert
  validation record, 2026-08-05).
- **Enumerator cross-validation**: partition-based clause generation agrees
  with brute-force product enumeration on all cells `t ∈ {3,…,7}`,
  `n ∈ {8,13,19}`.

First differences in `u`:
- `t=3`: 9, 9, 9, **8, 10**, 9, 9, 9 — the line `9u−13`, broken only by the
  `u = 7` dip (§6).
- `t=4`: 16, **2**, 10, 8, 11 — no linear law; the tail-slope-8 hypothesis

is not a perturbation of the sandwich construction. The `t = 3` row is the
one place the data resolves into a clean statement — Conjecture A below.

## 6. Extremal structure of the (3,3,u) family — certified by enumeration

For each computed `u` the complete set of valid colorings of `[1, S−1]` was
enumerated (counts matching Ahmed–Schaal's published counts wherever they
exist — §4). The structure is rigid everywhere except `u = 7`:

**For u ∈ {4, 5, 6, 8, 9}** (CERTIFIED at each listed u; *not* a claim for
general u):
- `S(3;3,3,u) = 9u−13`, and the extremal colorings of `[1, 9u−14]` are
  **exactly** a fixed mirror-symmetric skeleton with `u−2` completely free
  ternary slots at positions `2u+1+5j` (`j = 0,…,u−3`), each slot taking all
  three colors independently — `2·3^{u−2}` extremals on the nose
  (18, 54, 162, 1458, 4374), the factor 2 being the swap of the two Schur
  colors.
- The maximal `L(u)`-class size is exactly `5(u−2)`, attained by palindromic
  extremals; at maximum, the two Schur classes hold `4(u−1)` elements.

**At u = 7, every one of those regularities breaks at once** except the
`L(u)`-class law: `S = 49 = 9·7−14` (one below the line through every other
computed point); there are `846 = 2·3²·47` extremals — not a power-of-three
family — falling into at least two structural families; 37 of the 48
positions are non-constant across the orbit; the maximal class-2 size is
still `5(u−2) = 25` but no maximal extremal is palindromic, and the Schur
classes at maximum hold only `23 = 4(u−1)−1` elements. The deficit of
`S(3;3,3,7)` is a deficit of the *Schur pair's* capacity against this
`L(7)`-class, not of the `L(7)`-class itself.

**Conjecture A (new, this session).** `S(3;3,3,u) = 9u−13` for every
`u ≥ 4` except `u = 7`, i.e. for all `u ≥ 8` the slot-skeleton family
persists. The conjecture was stated from the data for `u ≤ 9` and then
**tested as a prediction twice**: at `u = 10` the value (77), the extremal
count (`2·3⁸ = 13122`), the slot positions (`21+5j`) and the maximal class
size (40) all landed exactly as predicted, and at `u = 11` the predicted
value 86 was then certified as well. Certified for
`u ∈ {3,…,11} ∖ {7}`; open beyond. The skeleton prefixes share their first
ten cells `0110201102` for `u = 8,9,10` but continue non-uniformly, which
is why the session ends with a conjecture and not a construction proof.

## 8. Reproducibility

Everything in this note is emitted by the scripts in this directory (see
README for the table); certificates in `certs/`; per-run logs in `data/`.
CNF files regenerate deterministically; `data/results_a1.csv` and
`data/cnf_hashes.txt` record their sha256. Total session compute: well under
two CPU-hours of successful solver time on 4 cores / 15 GB (the certified
runs sum to minutes — the largest single certified boundary, `(4,5,8)` at
`n = 111`, took 113 s + 85 s); the failures (three OOM-killed attempts at
`(4,4,10)`, three container restarts) cost more wall time than all successes
combined. No randomness anywhere; there are no seeds.

   5, mirror symmetry) is understood; the missing piece is a uniform
   description of the prefix blocks.

   one element against `L(7)`, and why only there? (Today it is a 35 KB

3. `S(3;4,4,10) ?= 109` and the rest of the `(4,4,u)` ladder — blocked today
