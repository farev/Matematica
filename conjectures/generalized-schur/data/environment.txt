Session 2026-08-07, cloud sandbox (Claude Code scheduled research session).

Hardware: 4 CPU cores, 15 GB RAM.
OS: Linux 6.18.5-fc-v18 (Ubuntu 24.04 userland).
Python 3.11.15; python-sat 1.9.dev7 (solvers used: Glucose42 for every
proof-logged boundary run, Cadical153 for exploration probes only).
gcc 13.3.0 (compiles tools/satcert/rup_check.c and check_coloring.c).

No randomness anywhere in the pipeline: the CNF encoder is deterministic
(sorted clause supports, fixed variable numbering v(x,j) = (x-1)*k + j + 1),
solver runs are single-threaded with default deterministic settings, so
there are no seeds to record. CNF files are regenerable byte-identically;
data/results*.csv records each boundary CNF's SHA-256.

Primary source read in-session (first primary source available to any
session in this repository since 2026-08-01):

  author preprint fetched from
