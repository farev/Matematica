# The first upper bound for Λ(8,2): a machine case analysis in the Lehmer style

*Research note, 2026-09-02. AI-assisted (Claude; the computation was carried out by a
subagent to a written specification and audited by the session). Labels follow the
repository convention.*

## Abstract

Let `Λ(k,2)` be the limit superior over primes `p` of the least `r` such that `r` and
`r+1` are both `k`-th power residues modulo `p`. Brillhart, Lehmer and Lehmer [BLL]
determined `Λ(k,2)` for `k ≤ 7` by a machine case analysis and gave only `Λ(8,2) ≥
1,200,744`. We complete the case analysis for `k = 8`, obtaining

> **Theorem.** `1,200,744 ≤ Λ(8,2) ≤ 1,508,324`.

The upper bound is unconditional and certified: an exhaustive decision tree over the
8th-power characters of the primes `< 300`, with the parity constraint on 2 and one
child per orbit of the unit group, has 3,499,913 leaves, each settled by a pair of
consecutive 293-smooth 8th-power residues `(n, n+1)` with `n ≤ 1,508,324`; an
independent checker verifies exhaustiveness and every leaf. (A first certificate with
the primes `≤ 113` gives `1,794,897`.) The lower bound is BLL's, re-verified. The exact
value remains open.

## 1. Setting

For a prime `p ≡ 1 (mod k)` fix a character `χ` of order `k` on `(Z/p)^*` and write
`R(q) ∈ Z/k` for the index with `χ(q) = ζ^{R(q)}`. An integer `n = Π q^{e_q}` prime to
`p` is a `k`-th power residue iff `Σ e_q R(q) ≡ 0 (mod k)`. Hence, for primes `p` larger
than every prime factor of `n(n+1)`, whether `(n, n+1)` is a pair of consecutive residues
depends only on the *case vector* `(R(q))_q` on the primes dividing `n(n+1)`. Changing
the generator of the character group replaces `R` by `uR`, `u ∈ (Z/k)^*`, which does not
change residue status.

For `k = 8` and `p ≡ 1 (mod 8)`, 2 is a quadratic residue, so `χ(2)^4 = 1`: `R(2)` is
even. This is the constraint that made BLL's general theorem inapplicable ([BLL] §8:
"Since 2 is a quadratic residue of `p = 8m+1`, we cannot choose `R(2) = 1`").

For primes `p ≢ 1 (mod 8)` the 8th-power residues are the `d`-th power residues with
`d = gcd(8, p−1) ∈ {2, 4}`, so `r(8,2,p) = r(d,2,p) ≤ max(Λ(2,2), Λ(4,2)) + o(1) = 1224`
for large `p`. The limit superior is therefore governed by `p ≡ 1 (mod 8)`.

## 2. The case tree

Fix a finite set `S` of primes and a bound `L`. A *trial pair* is `(n, n+1)` with `n ≤ L`
and both members `S`-smooth (all consecutive such pairs are computed by
`smoothpairs.py`; for the first 13 primes there are 869 in total, OEIS A002071, and the
program reproduces this). A node of the tree is a partial assignment `A` of values in
`Z/8` to some primes of `S` (with `A(2)` even). A trial pair is *settled* at `A` if all
primes of `n(n+1)` are assigned and both residue sums vanish; *dead* if some member can
never become a residue under any extension (the achievable sums form the subgroup
generated by `gcd(e_q·s_q, 8)` over the unassigned primes, `s_2 = 2`, `s_q = 1`); *open*
otherwise. At a node, the least open admitted pair is branched on: its smallest
unassigned prime `q` receives one child per orbit of the allowed values under the current
stabiliser `H ≤ (Z/8)^*` (units fixing all earlier decisions); the child's stabiliser is
the stabiliser of its value in `H`. A settled pair closes the leaf with value `n`; if no
admitted pair is open the next prime of `S` is admitted (BLL's "dimension window"); if all
primes are admitted the leaf is *unsettled*.

**Lemma 2.1 (exhaustiveness).** Let `R` be any assignment of `Z/8` to the primes of `S`
with `R(2)` even. Then there is a leaf `ℓ` and a unit `u` such that `uR` extends the
assignment of `ℓ`.

*Proof.* Walk down from the root. At a node with branching prime `q` and stabiliser `H`,
the current (already transformed) assignment `R'` agrees with the node on all decided
primes; `R'(q)` lies in the orbit under `H` of some child value `v`, say `R'(q) = u·v`
with `u ∈ H`; replace `R'` by `u^{-1}R'`, which fixes all decided values (`u ∈ H`) and
sends `R'(q)` to `v`. Continue into the child `v`. ∎

**Proposition 2.2.** If every leaf is settled, then for every prime `p ≡ 1 (mod 8)`
larger than every prime of `S`, `r(8,2,p) ≤ U := max_ℓ n_ℓ`. Consequently `Λ(8,2) ≤ U`.

*Proof.* Apply Lemma 2.1 to the character indices of `p`; the leaf's pair `(n_ℓ, n_ℓ+1)`
consists of `S`-smooth numbers, all of whose primes are assigned at the leaf, and both
residue sums vanish for `uR`, hence for `R`. As `p` exceeds every prime of `S`, `p ∤
n_ℓ(n_ℓ+1)`. Together with §1 for `p ≢ 1 (mod 8)` this gives the limit superior. ∎

Nothing in the upper bound requires the trial-pair list to be complete, the tree to be
minimal, or any assignment to be realisable by primes.

## 3. The certificate and the checker

`tree2` writes one line per leaf, `q₁=v₁ q₂=v₂ … | n` (decisions in order; `n = −1`
if unsettled), in depth-first order. `check_tree2.py` (69 lines, exact integer
arithmetic) re-reads the pairs file and verifies: (i) at every internal node the children's
values, expanded by the node's stabiliser, cover all allowed values of the branching prime
(the stabiliser is recomputed by the checker from the decisions); (ii) every leaf's `n`
is `≤ L`, occurs in the pairs list, and both members are residues under the leaf's own
assignment with all their primes assigned (exponents reduced mod 8); (iii) no leaf is
unsettled. The session's audit added `audit_pairs.py`, which verifies every line of the
pairs files (`Π = n`, `Π = n+1`, all bases prime by `sympy.isprime`), and re-ran the
checker and the controls. Given (i)–(iii) and a correct pairs file, Proposition 2.2
applies.

Hence **`Λ(8,2) ≤ 1,508,324`** (CERTIFIED). The number is what the primes below 300
give; whether a still larger prime set would settle the 108 vectors earlier is not known.

## 6. The lower bound and attempts to raise it

BLL's Table V vector (`data/tableII_k8.txt`) has least pair exactly `1,200,744` by an
exact sieve over all smaller `n`, so `Λ(8,2) ≥ 1,200,744` provided the vector is realised
by infinitely many primes — Mills' theorem (1963; for `k = 8` the condition is exactly
that `R(2)` is even), as BLL invoke it; this session did not re-read Mills.

Attempts to find a better vector (all NUMERICAL, negative): single-prime repair from BLL's
vector reaches a genuine impasse at `1,200,744`; a complete backjumping search with BLL's
vector fixed except at the six impasse primes `{5, 7, 13, 17, 29, 109}` (also with 2 and
3 free) exhausts with no solution below `1.3 M`; with only the primes `≤ 1000` fixed, the
pair `1200744/1200745` is forced; greedy extension of 36 of the 108 unsettled `S ≤ 300`
vectors stalls at `≤ 1,088,867`; the complete DFS does not finish at `10⁶` scale in ten
minutes.

## 7. What is and is not shown

* Proved: `Λ(8,2) ≤ 1,508,324`, certified, unconditional. Not proved: the exact value.
  BLL64 conjectured nothing explicit for `k = 8`; the gap `[1,200,744, 1,508,324]` is where
  a further session should work (the 108 case vectors unsettled just below `1,508,324`
  are the natural cubes: a realisable full extension of one of them with no pair below
  `1,200,744` would raise the lower bound; a larger prime set may settle them earlier).
* Sources checked today: [BLL] (text; the `1200744` statement and Table V vector),
  erdosproblems.com/436 (page), OEIS A002071. Secondary: Mills 1963 (subagent), Hildebrand
  1991 (not read), Rabung–Jordan 1970 (subagent).
