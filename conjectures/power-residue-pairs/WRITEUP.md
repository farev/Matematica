# Session narrative — 2026-09-02 (pivot line)

This problem was the pre-declared pivot of the Kobon session (see
`conjectures/kobon-triangles/WRITEUP.md` and the daily log). It was run in parallel by a
subagent from 12:03 to 13:40 UTC under a written specification: read
Brillhart–Lehmer–Lehmer and Rabung–Jordan first, settle the realisability question for
`k = 8`, build the tree with an independent checker, reproduce `k = 3..7` before claiming
anything about `k = 8`, then attempt the lower bound.

## What the subagent did, in order

1. Read BLL64 and Mills 1963. Identified the "not covered" remark as BLL's own §6 theorem
   (whose proof needs `R(2) = 1`), and Mills' Theorem 3 as the realisability statement
   (for `k = 8`: `R(2)` even, odd primes free).
2. Consecutive smooth pairs (`smoothpairs.py`), checked against OEIS A002071.
3. A first tree (`tree.c`) that branched on the least open pair regardless of prime size:
   more than `10⁸` leaves and a 10 GB certificate before it was killed — by the session,
   from outside, because the disk was minutes from full (the Kobon cube proofs were being
   written at the same time). Abandoned.
4. `tree2.c` with BLL's "dimension window" (admit primes in increasing order), unit-orbit
   branching, gzip certificates; `check_tree2.py` as an independent streaming checker.
5. Controls `k = 2..7`: all five known values reproduced exactly, with gaps appearing at
   `L = Λ − 1` (sharpness); BLL Table II vectors re-sieved.
6. `k = 8`: sweeps in `L` with `S ≤ 113` (gaps 734 → 539 → 254 → 0 at 1.8 M); certificate
   at `L = 1.8 M` checked; also `L = 2 M` and `10⁷`.
7. Lower bound: BLL's vector re-verified; repair, backjumping and greedy searches — all
   negative.
